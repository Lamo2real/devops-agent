# Weekly operations report

Every week, write a short operations report for the team:

1. Investigations in the last 7 days: count, alarms that started them,
   median time to root cause, and how many were duplicates or noise.
2. Recurring problems and the GitHub issues opened for them, with status.
3. Flapping or noisy alarms that should be tuned (consecutive periods,
   thresholds), with a concrete suggestion per alarm.
4. Risks seen in recent changes (deployments, configuration) that have not
   caused an incident yet.

Keep it under one page. Do not include personal data.
